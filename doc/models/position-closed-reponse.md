
# Position Closed Reponse

Represents the result of asking the api to close a position.

*This model accepts additional fields of type array.*

## Structure

`PositionClosedReponse`

## Fields

| Name | Type | Tags | Description | Getter | Setter |
|  --- | --- | --- | --- | --- | --- |
| `symbol` | `string` | Required | Symbol name of the asset | getSymbol(): string | setSymbol(string symbol): void |
| `status` | `string` | Required | Http status code for the attempt to close this position | getStatus(): string | setStatus(string status): void |
| `body` | [`?Order`](../../doc/models/order.md) | Optional | The Orders API allows a user to monitor, place and cancel their orders with Alpaca.<br><br>Each order has a unique identifier provided by the client. This client-side unique order ID will be automatically generated by the system if not provided by the client, and will be returned as part of the order object along with the rest of the fields described below. Once an order is placed, it can be queried using the client-side order ID to check the status.<br><br>Updates on open orders at Alpaca will also be sent over the streaming interface, which is the recommended method of maintaining order state. | getBody(): ?Order | setBody(?Order body): void |
| `additionalProperties` | `array<string, array>` | Optional | - | findAdditionalProperty(string key): array | additionalProperty(string key, array value): void |

## Example

```php
use TraderApiLib\Models\Builders\PositionClosedReponseBuilder;
use TraderApiLib\Models\Builders\OrderBuilder;
use TraderApiLib\Models\OrderType;
use TraderApiLib\Models\OrderSide;
use TraderApiLib\Models\TimeInForce;
use TraderApiLib\Utils\DateTimeHelper;
use TraderApiLib\ApiHelper;

$positionClosedReponse = PositionClosedReponseBuilder::init(
    'symbol4',
    'status4'
)
    ->body(
        OrderBuilder::init(
            'symbol2',
            OrderType::TRAILING_STOP,
            OrderSide::BUY,
            TimeInForce::DAY
        )
            ->id('id6')
            ->clientOrderId('client_order_id6')
            ->createdAt(DateTimeHelper::fromRfc3339DateTime('2016-03-13T12:52:32.123Z'))
            ->updatedAt(DateTimeHelper::fromRfc3339DateTime('2016-03-13T12:52:32.123Z'))
            ->submittedAt(DateTimeHelper::fromRfc3339DateTime('2016-03-13T12:52:32.123Z'))
            ->notional('notional2')
            ->qty('qty2')
            ->additionalProperty('exampleAdditionalProperty', ApiHelper::deserialize('{"key1":"val1","key2":"val2"}'))
            ->build()
    )
    ->additionalProperty('exampleAdditionalProperty', ApiHelper::deserialize('{"key1":"val1","key2":"val2"}'))
    ->build();
```
