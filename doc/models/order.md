
# Order

The Orders API allows a user to monitor, place and cancel their orders with Alpaca.

Each order has a unique identifier provided by the client. This client-side unique order ID will be automatically generated by the system if not provided by the client, and will be returned as part of the order object along with the rest of the fields described below. Once an order is placed, it can be queried using the client-side order ID to check the status.

Updates on open orders at Alpaca will also be sent over the streaming interface, which is the recommended method of maintaining order state.

*This model accepts additional fields of type array.*

## Example

```php
use TraderApiLib\Models\Builders\OrderBuilder;
use TraderApiLib\Models\OrderType;
use TraderApiLib\Models\OrderSide;
use TraderApiLib\Models\TimeInForce;
use TraderApiLib\Utils\DateTimeHelper;
use TraderApiLib\Models\AssetClass;
use TraderApiLib\Models\OrderClass;
use TraderApiLib\Models\OrderStatus;
use TraderApiLib\ApiHelper;

$order = OrderBuilder::init(
    'symbol8',
    OrderType::STOP,
    OrderSide::BUY,
    TimeInForce::DAY
)
    ->id('id6')
    ->clientOrderId('client_order_id6')
    ->createdAt(DateTimeHelper::fromRfc3339DateTime('2016-03-13T12:52:32.123Z'))
    ->updatedAt(DateTimeHelper::fromRfc3339DateTime('2016-03-13T12:52:32.123Z'))
    ->submittedAt(DateTimeHelper::fromRfc3339DateTime('2016-03-13T12:52:32.123Z'))
    ->assetClass(AssetClass::US_EQUITY)
    ->notional('notional2')
    ->qty('qty2')
    ->orderClass(OrderClass::BRACKET)
    ->status(OrderStatus::NEW_)
    ->additionalProperty('exampleAdditionalProperty', ApiHelper::deserialize('{"key1":"val1","key2":"val2"}'))
    ->build();
```
